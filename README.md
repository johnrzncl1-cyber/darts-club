# Сайт «Дартс Клуб»

Статический сайт программы: `index.html`, стили в `css/`, скрипт в `js/`, шрифт Fira Sans Condensed в `fonts/` (лицензия OFL), снимки экранов в `img/shots/`, мультяшные аватары в `img/av/`.
Внешних зависимостей нет: шрифт лежит рядом, сайт открывается и без доступа к Google.

## Что заполнить

| Где | Что |
|---|---|
| `index.html`, блок «Оставить заявку» (комментарий `КОНТАКТЫ`) | телефон, почта, Telegram, ВКонтакте, данные разработчика |
| `index.html`, раздел «Цены» | вместо `X XXX ₽` и `[условия]` — свои цены и условия обновлений |
| `js/site.js`, первые строки | `email` — почта для заявок, `endpoint` — адрес сервиса FormSubmit, `tag` — начало темы письма |

Заявки отправляются через бесплатный сервис FormSubmit на darts-center@yandex.ru. Тема письма: `#дартс-центр.лицензии <клуб> <e-mail>`. При первой заявке FormSubmit присылает на этот адрес письмо с кнопкой **Activate Form** — её нужно нажать один раз, после этого заявки приходят сразу.

## Размещение на GitHub Pages (бесплатно)

1. Зарегистрируйтесь на github.com и создайте публичный репозиторий, например `darts-club`.
2. На странице репозитория: **Add file → Upload files**, перетащите всё содержимое этой папки (вместе с папками `css`, `js`, `fonts`, `img` и файлом `.nojekyll`), нажмите **Commit changes**.
3. **Settings → Pages**: Source — *Deploy from a branch*, Branch — `main`, папка `/ (root)`, **Save**.
4. Через 1–2 минуты сайт будет доступен по адресу `https://<ваш-логин>.github.io/darts-club/`.
5. Свой домен (по желанию): там же, в **Settings → Pages → Custom domain**, и запись CNAME у регистратора домена.

Обновление сайта — снова **Upload files** с заменой файлов.

## Другие варианты

- **Yandex Object Storage** — статический хостинг в Яндекс Облаке, стабильно открывается в России, но тарифицируется (копейки за хранение и трафик).
- **Cloudflare Pages, Netlify, Vercel** — бесплатны, но из России открываются с перебоями; Vercel на бесплатном тарифе — только для некоммерческих сайтов.
