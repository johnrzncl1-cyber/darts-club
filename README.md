# Сайт программы «Дартс-Центр»

Статический сайт: `index.html`, стили в `css/`, скрипт в `js/`, шрифт Fira Sans Condensed в `fonts/` (лицензия OFL), снимки экранов в `img/shots/`, фото игроков в `img/av/`, ролик в `video/`.
Внешних зависимостей нет: шрифт и ролик лежат рядом, сайт открывается и без доступа к Google.

Игроки и результаты на снимках вымышленные.

## Заявки в IntraService

Форма «Оставить заявку» отправляет заявку в функцию Яндекс Облака (`proxy/index.js`), а функция создаёт задачу в IntraService в сервисе 1 «Лицензии Дартс-Центр». Пароль APIUser хранится только в настройках функции и не попадает в файлы сайта.

1. Создайте функцию по инструкции «Дартс-Центр: заявки с сайта в IntraService через Яндекс Облако».
2. В `js/site.js`, в первых строках, впишите адрес функции: `api: 'https://functions.yandexcloud.net/…'`.
3. Увеличьте число в `?v=` у `css/style.css` и `js/site.js` в `index.html`, чтобы браузеры посетителей взяли новый скрипт.

Пока `api` пустой или функция недоступна, заявка уходит письмом через FormSubmit на darts-center@yandex.ru с темой `#дартс-центр.лицензии <клуб> <e-mail>`. При первом письме FormSubmit присылает ссылку **Activate Form** — её нужно нажать один раз.

## Публикация

Сайт размещён на GitHub Pages: ветка `main`, папка `/ (root)`. Изменения на сайте появляются через 1–2 минуты после коммита.
